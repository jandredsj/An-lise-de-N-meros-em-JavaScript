# An-lise-de-N-meros-em-JavaScript
Programa desenvolvido em JavaScript que solicita 10 números ao usuário, armazena os valores em um array, separa os números pares e ímpares e identifica o maior e o menor número informado. Projeto criado para praticar lógica de programação, manipulação de arrays, estruturas de repetição, condicionais e operações matemáticas.
